ResMon 1.7.6 - correctness and efficiency pass

Fixed:
- IDWriteTextFormat leak. DiscardDeviceResources() never reset the five text
  formats, and CreateDeviceResources() rebuilt them with ComPtr::GetAddressOf(),
  which overwrites the stored pointer without releasing it. Text formats are
  device independent, so they are now created once in CreateTextFormats().
- CPU clock on machines with more than 64 logical processors.
  CallNtPowerInformation(ProcessorInformation) only fills entries for the
  calling thread's processor group, but the average divided by the all-groups
  count, so the zeroed entries dragged the result down. Only populated entries
  are averaged now.
- ExecuteCommand saved the settings a second time after IDM_EXIT had already
  destroyed the window.

Efficiency:
- ContainsInsensitive() used to copy and lower-case both strings on every call,
  and ReadGpu() calls it twice per GPU counter instance - 648 instances on the
  development machine, so roughly 2600 wstring allocations every sample. It now
  uses StrStrIW, which searches in place.
- SaveSettings() writes one section at a time instead of one key at a time.
  Each WritePrivateProfileStringW call rewrites the whole file, so a single
  menu click used to rewrite settings.ini fourteen times.
- IsAutostartEnabled() no longer allocates a 64 KB stack buffer for a value it
  discards.

Cleanups:
- MetricsSampler::Sample() no longer takes an unused elapsed-seconds argument;
  App::lastTick_ existed only to compute it.
- One helper replaces three copies of the PDH counter-array read sequence.
- MetricsSampler has copy/assignment deleted; it owns raw PDH query handles.
- NvidiaTemperatureReader::Shutdown() clears its entry points.
- The legacy monitor/show_disk key is no longer written; it is still read once
  so existing settings files migrate.
- Startup failures show a message box instead of exiting silently.

Hardening:
- The embedded PawnIO installer is extracted into a freshly created, randomly
  named directory under %TEMP% instead of a fixed path, so another process
  running as the same user cannot swap the file before it is launched elevated.
- Waiting for the installer pumps messages, with input to the widget disabled,
  so the window keeps painting instead of being marked "not responding".

Everything else from 1.7.x remains: native C++/Win32, optional PawnIO CPU
temperatures, NVML NVIDIA GPU temperature support, row visibility controls,
themes, opacity, and short-lived easing.
